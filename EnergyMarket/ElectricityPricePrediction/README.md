# Day-Ahead Electricity Price Forecasting

ML pipeline to predict day-ahead locational marginal prices (LMPs) in the PJM wholesale power market.
LPMs are hourly, financially binding wholesale electricity prices determined for specific locations on a power grid for the following operating day.
They reflect the total cost to supply the next megawatt (MW) of energy at a specific node while factoring in generation costs, power transmission constraints congestion, and energy losses.
The predictions are based on historical price and weather data.

Accurate forecasts enable:
- Efficient generation asset dispatch
- Energy trading and arbitrage strategies
- Demand response program optimization

This project demonstrates a **complete forecasting pipeline**:
- Load and clean historical price and weather data
- Engineer lag and calendar features
- Train a LightGBM model on 2022–2023 data
- Evaluate against an out-of-sample Q4 2023 test period
- Compare against a naïve benchmark (same hour yesterday)


# Data Sources

- Prices: [EIA Wholesale Markets CSV](https://www.eia.gov/electricity/wholesalemarkets/data.php?rto=pjm) (no API key required). Data correspond to the Allegheny Power System (APS) zone (Pennsylvania, Virginia, West Virginia, and Maryland) within the PJM Interconnection grid.
  - Raw Data Features [only the useful ones]:  "UTC Timestamp (Interval Ending)", "Allegheny Power System LMP"
- Weather: [Open-Meteo Historical API](https://open-meteo.com/en/docs/historical-weather-api) for Philadelphia (no API key required):
  - API arguments: latitude, longitude, start_date, end_date, hourly, timezone, temperature_unit


# Features

- `hour_of_day`: Captures intraday price shape (peaks at morning/evening)
- `day_of_week`: Weekday vs weekend demand patterns
- `month`: Seasonal heating/cooling demand
- `is_weekend`: Binary demand indicator
- `temperature_2m`: Temperature (°F) in Philadelphia
- `price_lag_24h`: Price 24 hours prior
- `price_lag_48h`: Price 48 hours prior
- `price_lag_168h`: Price 168 hours prior (7 days)
- `price_roll_7d_mean`: 7-day rolling average = smoothed price level signal


# Model

**Split:** Chronological — train on Jan 2022–Sep 2023, test on Oct–Dec 2023  
**Algorithm:** LightGBM (gradient boosted trees)
**Baseline:** Naïve benchmark — predict each hour's price = same hour yesterday

LightGBM was chosen for its ability to capture non-linear interactions (e.g., hot summer afternoons driving air conditioning load spikes) and its robustness to feature scaling differences (no normalization needed).
It is also widely used in energy market forecasting.


# Project Structure

```
ElectricityPricePrediction/
├── data/
│   └── sample_pjm_lmp.csv      # 2022–2023 PJM APS hourly LMP
├── src/
│   ├── ingest.py               # Data loading, weather API, merging
│   ├── features.py             # Calendar, weather, and lag features
│   ├── model.py                # LightGBM training and evaluation
│   └── visualize.py            # Publication-quality plot exports
├── outputs/
│   └── figures/                # PNG exports
├── forecasting.ipynb           # End-to-end narrative notebook
├── README.md
└── requirements.txt
```

ingest.py:
- Generate data/sample_pjm_lmp.csv from EIA source files.
  - Downloads PJM day-ahead LMP CSVs for the specified years from the EIA website, extracts the Allegheny Power System (APS) zone price column, and saves a clean two-column CSV (utc_timestamp, lmp_usd_mwh).
  - Downloads weather data from open-meteo.com
- Load, clean, and merge electricity price and weather data.

features.py:
- Feature engineering
- All features are constructed using only past information - no data leakage.
- Lag features use shift(), which on a sorted chronological DataFrame always pulls from earlier timestamps.

model.py:
- LightGBM training, naive benchmark, and evaluation.

visualize.py:
- Publication-quality plots for the forecasting pipeline.
- `matplotlib.use('Agg')` ensures workflow works in headless environments (CI, servers) and inside Jupyter when no display is available.


# Using this repo

Requires **Python 3.9+**.

```bash
pip install -r requirements.txt
jupyter notebook forecasting.ipynb
```
Figures are generated by running `forecasting.ipynb` and saved to `outputs/figures/`. 


# Potential Future Enhancements

- **SHAP explanations**: per-prediction feature attribution for model interpretability
- **Load data**: add system load as an input feature. Demand is the primary driver of LMP during peak periods
- **Additional weather variables**: wind speed, cloud cover, heating/cooling degree days to capture demand-side drivers more precisely  
- **Fuel price signals**: natural gas spot prices explain a significant share of off-peak price variation in gas-heavy dispatch regions
- **Quantile regression**: produce prediction intervals instead of point forecasts, enabling risk-aware bidding strategies
